#📚 My Read Books – Full Stack App with React (Chakra UI) + Node.js
This is a full stack CRUD application for managing books I've read, built using React.js with Chakra UI and a Node.js + Express backend. Originally based on a YouTube tutorial about adding products, I customized the project to focus on a personal book tracker. It also features a sleek light/dark mode toggle for better UX.

#🔧 Tech Stack
##Frontend
React.js
Chakra UI (includes light/dark mode toggle)

##Backend
Node.js
Express.js
MongoDB + Mongoose

#✨ Features
✅ Add a book you’ve read
✏️ Edit book details
❌ Delete a book
📚 View a list of all read books
🌗 Toggle between light and dark themes
