# 📚 My Read Books – Full Stack App with React (Chakra UI) + Node.js

This is a full-stack CRUD application for managing books I've read, built using **React.js** with **Chakra UI** and a **Node.js + Express** backend. Originally based on a YouTube tutorial about adding products, I customized the project to focus on a personal book tracker. It also features a sleek light/dark mode toggle for better UX, and **authentication** for secure access.

---

## 🔧 Tech Stack

### Frontend
- **React.js**
- **Chakra UI**

### Backend
- **Node.js**
- **Express.js**
- **MongoDB + Mongoose**

---

## ✨ Features
- login
- ✅ Add a book you’ve read
- ✏️ Edit book details
- ❌ Delete a book
- 📚 View a list of all read books
- 🌗 Toggle between light and dark themes
-logout
---

## 🌟 About the Project

This app was designed to help me keep track of the books I've read. While it started as a simple CRUD implementation inspired by a YouTube tutorial, I expanded its functionality to suit my needs as a personal book tracker. The addition of Chakra UI ensures a modern, responsive design with seamless theme switching between light and dark modes.
